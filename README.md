# ⛽ Pipeline ETL: Séries Históricas de Preços de Combustíveis (ANP)

## 🎯 Sobre o Projeto
Este projeto consiste no desenvolvimento de um pipeline de Engenharia de Dados ponta a ponta (End-to-End) para a extração, tratamento, modelagem e carga (ETL) dos microdados públicos de preços de combustíveis e GLP disponibilizados pela ANP (Agência Nacional do Petróleo, Gás Natural e Biocombustíveis). 

O objetivo é automatizar a ingestão desses dados históricos (gasolina, etanol, diesel, GLP, etc.) para alimentar um banco de dados relacional, permitindo análises de variação de preços e consultas otimizadas através de *Views* analíticas.
